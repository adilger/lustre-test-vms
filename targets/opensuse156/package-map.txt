# Translates RHEL package names (used in targets/common/packages-*.txt)
# to openSUSE Leap package names.  Format:
#
#   rhel_name  suse_name [suse_name2 ...]
#
# A suse_name of "-" means "skip this package on openSUSE".
# Packages not listed here pass through unchanged (assumes the name
# matches on both distros).
#
# Lines starting with # and blank lines are ignored.
